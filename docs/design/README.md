в разметку: техника и решение живут вместе, иначе токен правится без понимания, зачем он.

## Ранг

В репозитории лежит скилл `.claude/skills/design-taste-frontend/` — антислоп-правила для
новых поверхностей. **Эта папка старше его по рангу.** Бан-лист скилла запрещает то, что
здесь является осознанной подписью v1 (нумерованные эйбрау `§ 01`, средние точки, em-dash,
хайрлайны как декор, курсорный blob, Inter как основная гарнитура). Скилл применяется, когда
проектируется что-то новое; во всем, что сайт уже делает, решает эта папка.

## Что считается изменением дизайн-системы

Правка файлов этой папки нужна, когда меняется палитра, типографическая шкала, ритм секций,
правила моушена, набор токенов, утилита в `tailwind.config.ts`, шрифт или способ доставки
иконок. Обычная верстка внутри существующих правил документации не требует.
