# v2 — живая система (`/`, `/ru/`, `/uz/`)

Полный редизайн, а не рескин: с v1 общий только контентный конвейер. Все, что ниже, решено
намеренно и записано, чтобы это не «поправили» обратно в сторону v1.

**Читатель:** нанимающий менеджер и рекрутер. **Язык:** premium-consumer, нативный CSS плюс
утилиты Tailwind и scroll-driven анимация. **Ручки:** `DESIGN_VARIANCE 9`,
`MOTION_INTENSITY 8`, `VISUAL_DENSITY 3`.

## Палитра — Cold Luxury

Холодные серебристо-серые нейтрали, хромированные поверхности, дымчатые линии и один
кобальтовый акцент: `230 68% 51%` в светлой теме, `227 72% 74%` в темной. Выбрано против двух
запретов: это не теплая медовая система v1 и не бежево-латунно-эспрессо, куда по умолчанию
скатывается premium-consumer бриф. Один акцент на всю страницу, в обеих темах.

Хардкод цвета в разметке запрещен: значение, которого нет в токенах, — это либо новый токен,
либо ошибка.

## Токены — `src/styles/v2.css`

Значения в HSL-компонентах без `hsl()`, чтобы Tailwind мог подставлять прозрачность.

| Токен             | Роль                                      |
| ----------------- | ----------------------------------------- |
| `--v2-bg`         | Фон страницы                              |
| `--v2-surface`    | Приподнятая поверхность, карточки, секции |
| `--v2-ink`        | Основной текст                            |
| `--v2-mut`        | Приглушенный текст                        |
| `--v2-line`       | Границы и хайрлайны                       |
| `--v2-accent`     | Кобальтовый акцент                        |
| `--v2-accent-ink` | Текст на акценте                          |
| `--v2-shadow`     | База теней                                |
| `--v2-sheen`      | Блики и градиентные заливки                |

`v2.css` **не импортирует** `global.css`. Каждый layout подключает ровно один файл стилей,
поэтому дизайны физически не пересекаются. Это не стилистическая деталь, а способ держать
архив живым без регрессий — не сводить файлы вместе.

## Две темы, одна система

Системная тема по умолчанию (`@media (prefers-color-scheme: dark)`); тумблер в шапке
закрепляет выбор — пишет `data-theme` на `<html>` и сохраняет значение. `:root[data-theme="…"]`
перебивает голый `:root` внутри медиазапроса, поэтому ручной выбор всегда выигрывает без
`!important`. Блокирующий инлайн-скрипт в `V2Layout` применяет сохраненное значение до первой
отрисовки — закрепленная тема не мигает. Удаление значения возвращает управление системе.

Темная тема объявлена **дважды** (медиазапрос и `[data-theme="dark"]`), светлая — в `:root` и
в `[data-theme="light"]`. Значения обязаны совпадать: правка одного блока без второго дает
разные цвета до и после клика по тумблеру.

Инверсия отдельной секции запрещена: какая тема активна, в той вся страница целиком.

## Мост в Tailwind — `tailwind.config.ts`

Токены подняты в утилиты аддитивно, поверх темы v1:

- цвета: `bg-v2-bg`, `bg-v2-surface`, `text-v2-ink`, `text-v2-mut`, `border-v2-line`,
  `bg-v2-accent`, `text-v2-accent-ink`
- шрифты: `font-geist`, `font-geist-mono`
- радиусы: `rounded-v2`, `rounded-v2-lg`

Утилиты v1 (`bg-background`, `text-primary`, `border-border`, `font-sans`, `font-display`,
`font-mono`) не тронуты.

## Типографика

Geist и Geist Mono, самохостинг через `@fontsource-variable` (`@import` в начале
`src/styles/v2.css`, никаких `<link>` на Google Fonts). Серифа нет вообще: скилл поименно
запрещает Instrument Serif, а это подписная гарнитура v1.

## Форма

Замок: панели 16px, медиа 20px, интерактив — полная пилюля. Других радиусов нет.

## Иконки

Только инлайн-SVG на этапе сборки: `@tabler/icons` через `?raw` для интерфейсных иконок,
`simple-icons` через `src/components/v2/logos.ts` — для брендовых марок. Иконочных шрифтов и
спрайтов в проекте нет, пути руками не рисуются.

## От чего v2 отказывается намеренно

Все перечисленное — подписи v1: нумерованные эйбрау секций, любые эйбрау вообще, средняя
точка как разделитель по умолчанию, em-dash в отрисованном тексте, хайрлайн как декор,
пленочное зерно, курсорный blob, бегущая строка текстом, живые часы.

## Подписные приемы

Настоящие марки Simple Icons (никогда не рисованные пути): логотипная бегущая строка под
героем и хайрлайн-сетка подписанных марок в секции стека. Липкие рельсы несут подпись секции,
а в «Опыте» — весь трек из шести ролей, пока колонка деталей скроллится. Портрет героя стоит
в хромированной раме (холодный блик плюс внутренний 1px хайлайт) и дрейфует на собственном
скролл-таймлайне.

## Моушен

У каждого эффекта одна работа:

| Эффект                                     | Работа                       | Как                                        |
| ------------------------------------------ | ---------------------------- | ------------------------------------------ |
| Раскрытие имени                            | иерархия, первое впечатление | keyframes по `clip-path`, стаггер по строкам |
| Дрейф портрета                             | глубина                      | `animation-timeline: view()`, ±3%          |
| Линия прогресса чтения                     | ориентация                   | `animation-timeline: scroll()` на 1px акценте |
| Пословесное проявление                     | темп открывающего тезиса     | `--i` на слово смещает `animation-range`   |
| Отрисовка правила                          | прибытие секции              | `scaleX` на акцентном подчеркивании        |
| Раскрытия при скролле                      | ритм                         | `view()`-таймлайны, без скролл-слушателей  |
| Счетчик цифр                               | притянуть глаз к числам      | `IntersectionObserver`, ease-out cubic     |
| Магнитная CTA                              | отклик                       | `pointermove` transform, без состояния     |
| Подъем карточки, подчеркивание, поворот `<details>` | отклик и состояние  | CSS-переходы                               |

Все обернуто в `prefers-reduced-motion`: счетчик и магнитная CTA выходят из скрипта целиком,
а scroll-driven раскрытия деградируют до просто видимого контента там, где view-таймлайны не
поддерживаются.

## Один скрипт

`V2Page.astro` несет единственный инлайн-островок — счетчик и магнитную CTA. Обоим нужны
покадровые значения, которых CSS-таймлайны выразить не могут. Больше на странице JavaScript
нет: сначала ищется CSS-решение (`:has`, `:target`, `animation-timeline`, `details`), и только
если его нет — инлайн-скрипт в существующем островке поверхности.
