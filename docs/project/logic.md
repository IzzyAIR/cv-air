# Логика: константы, хелперы, клиентские скрипты

Все, что не разметка и не контент: сборка URL, форматирование текста, иконки и те три
островка JS, которые реально доезжают до браузера.

## `src/consts.ts`

| Экспорт                            | Значение / роль                                          |
| ---------------------------------- | -------------------------------------------------------- |
| `SITE_URL`                         | Домен продакшена; дублирует `site` из `astro.config.mjs`  |
| `SITE_NAME`, `TWITTER_HANDLE`      | OG `site_name` и `twitter:site`                           |
| `OG_IMAGE`, `..._WIDTH`, `..._HEIGHT` | `/og-image.svg`, 1200×630                              |
| `LOCALE_MAP`                       | `Lang → "en_US" \| "ru_RU" \| "uz_UZ"`; для OG и `hreflang` (там через `replace("_", "-")`) |
| `pathFor(lang)`                    | Канонический путь v2: `/` для `en`                        |
| `v1PathFor(lang)`                  | Путь архива: `/v1`, `/ru/v1`, `/uz/v1`                    |
| `absoluteUrl(path)`                | `SITE_URL` + путь, аккуратно со слешами                   |

Абсолютные URL собираем только через `absoluteUrl` — иначе появляются `//` и битые
canonical.

## `src/components/v2/ui.ts`

Chrome-строки v2 и текстовые хелперы поверхности.

| Экспорт                | Что делает                                                                     |
| ---------------------- | ------------------------------------------------------------------------------ |
| `getUi(lang)`          | Словарь UI-строк v2: подписи навигации, секций, кнопок. Только «обвязка», не контент CV |
| `v2Href(lang, hash?)`  | Ссылка на v2-страницу локали, с якорем                                          |
| `v1Href(lang)`         | Ссылка на архив                                                                 |
| `noDash(s)`            | Меняет `—` на `-`: дизайн-скилл запрещает em-dash, а бандлы им полны            |
| `leadFrom(s, max=20)`  | Лид героя: берет целые предложения, пока укладывается в лимит слов              |
| `splitLead(h)`         | `"Проект — описание"` → `{ lead, text }` для жирного зачина; иначе `lead: ""`   |
| `stripUrl(url)`        | Снимает протокол и хвостовой слеш для показа ссылки текстом                     |

`getUi` — не замена контенту: как только строка становится частью CV (а не подписью
кнопки), ее место в `src/i18n/`.

## `src/components/v2/logos.ts`

`pick(key, label?)` достает марку из `simple-icons` по ключу вида `siReact` и отдает
`{ name, path }`. Два набора: `MARQUEE_LOGOS` (бегущая строка под героем, без подписей) и
`CORE_LOGOS` (подписанная сетка в секции стека, с ручными подписями там, где заголовок
пакета неточен: `siNextdotjs → "Next.js"`, `siAngular → "Angular 20"`).

SVG инлайнится на этапе сборки, сетевых запросов нет. **Не рисовать пути руками** — либо
марка есть в `simple-icons`, либо ее нет в списке.

## Клиентский JS: полный перечень

Весь JS сайта — три инлайн-островка. Ничего не гидрируется, бандла нет.

### 1. Pre-paint тема — `src/layouts/V2Layout.astro`

Читает `localStorage["v2-theme"]` и ставит `data-theme` на `<html>` до первой отрисовки.
Скрипт обязан оставаться синхронным и инлайновым в `<head>`: любой перенос вниз или в
модуль дает вспышку светлой темы.

### 2. Островок v2 — `src/components/v2/V2Page.astro`

Один IIFE:

- **Переключатель темы** — клик по `#v2-theme`, инверсия текущего значения
  (`data-theme`, иначе `prefers-color-scheme`), запись в `localStorage` в `try/catch`.
- Далее ранний выход при `prefers-reduced-motion: reduce` — все, что ниже, декоративно.
- **Счетчик цифр** — `IntersectionObserver` по `[data-count]`, `requestAnimationFrame`,
  ease-out-cubic, 900 мс, `unobserve` после первого срабатывания.
- **Магнитная CTA** — `[data-magnetic]`, сдвиг до 10 px по `pointermove`, сброс на
  `pointerleave`.

Скролл-слушателей нет и не должно быть: раскрытия секций и линия прогресса чтения сделаны
на `animation-timeline: view()` / `scroll()` в CSS.

### 3. Навбар v1 — `src/components/Navbar.astro`

Скролл-спай, мобильное меню, плавный скролл, класс «проскроллено». `id` секций выводятся
из `navLinks[].href`. Живет только на архивной поверхности.

Отдельно — два скрипта резюме (`localStorage`-тема хрома и пагинация), они описаны в файле
`resume.md` этого раздела.

## Правила для нового поведения

- Сначала ищем CSS-решение (`:has`, `:target`, `animation-timeline`, `details`).
- Если нужен JS — он инлайновый, в существующем островке поверхности, и уважает
  `prefers-reduced-motion`.
- Никаких зависимостей ради интерактива: клиентских рантаймов в проекте нет, и появление
  первого — архитектурное решение, а не деталь реализации.
