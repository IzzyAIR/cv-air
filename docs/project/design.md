# Дизайн: токены, темы, шрифты

Философия, палитра, типографика, моушен и запреты описаны в `DESIGN.md` в корне репозитория —
он старше по рангу, чем дизайн-скилл `.claude/skills/design-taste-frontend/`. Здесь только
техническая часть: где лежат токены и как они попадают в разметку.

## Две независимые системы

| Система | Файл                    | Поверхности     | Палитра                                   |
| ------- | ----------------------- | --------------- | ----------------------------------------- |
| v2      | `src/styles/v2.css`     | `/`, `/ru/`, `/uz/` | Cold Luxury: холодные серые + кобальт |
| v1      | `src/styles/global.css` | `/v1`, 404      | Теплая темная редакционная                |

`v2.css` **не импортирует** `global.css`. Каждый layout подключает ровно один файл, поэтому
стили дизайнов физически не пересекаются. Это не стилистическая деталь, а способ держать
архив живым без регрессий — не сводить файлы вместе.

## Токены v2 — `src/styles/v2.css`

Все значения в HSL-компонентах без `hsl()`, чтобы Tailwind мог подставлять прозрачность.

| Токен            | Роль                                     |
| ---------------- | ---------------------------------------- |
| `--v2-bg`        | Фон страницы                              |
| `--v2-surface`   | Приподнятая поверхность, карточки, секции |
| `--v2-ink`       | Основной текст                            |
| `--v2-mut`       | Приглушенный текст                        |
| `--v2-line`      | Границы и хайрлайны                       |
| `--v2-accent`    | Кобальтовый акцент                        |
| `--v2-accent-ink`| Текст на акценте                          |
| `--v2-shadow`    | База теней                                |
| `--v2-sheen`     | Блики и градиентные заливки               |

Темная тема объявлена **дважды**: в `@media (prefers-color-scheme: dark)` и в
`[data-theme="dark"]`; светлая — в `:root` и в `[data-theme="light"]`. Первое дает системную
тему без JS, второе — закрепление выбора пользователем. Значения обязаны совпадать: правка
одного блока без второго дает разные цвета до и после клика по тумблеру.

## Мост в Tailwind — `tailwind.config.ts`

Токены v2 подняты в утилиты аддитивно, поверх темы v1:

- цвета: `bg-v2-bg`, `bg-v2-surface`, `text-v2-ink`, `text-v2-mut`, `border-v2-line`,
  `bg-v2-accent`, `text-v2-accent-ink`
- шрифты: `font-geist`, `font-geist-mono`
- радиусы: `rounded-v2`, `rounded-v2-lg`

Утилиты v1 (`bg-background`, `text-primary`, `border-border`, `font-sans`, `font-display`,
`font-mono`) не тронуты. `darkMode: ["class"]`, `applyBaseStyles: false` — базовые стили
приходят из `global.css`, который импортирует только `BaseLayout`.

Хардкод цветов в разметке запрещен: значение, которого нет в токенах, — это либо новый
токен, либо ошибка.

## Шрифты

v2 и резюме — Geist и Geist Mono, самохостинг через `@fontsource-variable`: v2 подключает их
`@import`'ом в начале `src/styles/v2.css`, `ResumePage.astro` — прямым импортом во
frontmatter. Внешних запросов за шрифтами у этих поверхностей нет.

v1 — Inter, Instrument Serif и JetBrains Mono, и они тянутся `@import url(...)` из Google
Fonts в первой строке `src/styles/global.css`. Это единственный внешний запрос в проекте и
он касается только архивной поверхности; переносить эту схему на новые страницы не нужно.

## Иконки

Только инлайн-SVG на этапе сборки: `@tabler/icons` через `?raw` для интерфейсных иконок,
`simple-icons` через `src/components/v2/logos.ts` для брендовых марок. Иконочных шрифтов и
спрайтов в проекте нет.

## Что считается изменением дизайн-системы

Правка `DESIGN.md` требуется, когда меняется палитра, типографическая шкала, ритм секций
или правила моушена. Правка этого файла — когда появляется новый токен, новая утилита в
`tailwind.config.ts`, новый шрифт или новый способ доставки иконок.
