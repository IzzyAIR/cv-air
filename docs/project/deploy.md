# Сборка и деплой

Вывод — чистая статика. Ни сервера, ни рантайма, ни переменных окружения.

## Скрипты

| Команда           | Что делает                                       |
| ----------------- | ------------------------------------------------ |
| `npm run dev`     | Dev-сервер Astro с HMR — http://localhost:4321    |
| `npm run build`   | Статическая сборка в `./dist/`                    |
| `npm run preview` | Локальная отдача собранного `dist/`               |
| `npm run astro`   | Прямой доступ к CLI Astro                         |

Тест-раннера, линтера и форматтера в проекте нет. Проверка типов — `npm run astro check`.
Это единственный автоматический контроль перед коммитом; он же ловит рассинхрон локальных
бандлов после правки `src/types/cv.ts`.

Локфайлы в репозитории два: `package-lock.json` и `bun.lock`. Ставить зависимости можно любым
из менеджеров, но обновлять — тем же, которым ставили, чтобы не разъезжались версии.

## Конфигурация — `astro.config.mjs`

| Ключ                        | Значение                                                     |
| --------------------------- | ------------------------------------------------------------ |
| `site`                      | Домен продакшена; используется sitemap и абсолютными URL      |
| `trailingSlash`             | `"ignore"`                                                    |
| `build.inlineStylesheets`   | `"auto"` — мелкий CSS уезжает в HTML, запросов меньше         |
| `integrations`              | `@astrojs/tailwind` (`applyBaseStyles: false`), `@astrojs/sitemap` |

Sitemap настроен с `i18n` (`defaultLocale: "en"`, локали `en-US` / `ru-RU` / `uz-UZ`),
`changefreq: "monthly"`, `priority: 0.8` и фильтром, который выбрасывает `/v1` и `/resume`.

Домен указан в двух местах: `site` в конфиге и `SITE_URL` в `src/consts.ts`. При переезде
правим оба, иначе canonical и OG будут указывать на старый адрес.

## Что попадает в `dist/`

HTML по одному файлу на маршрут, CSS, самохостинговые шрифты Geist, изображения,
обработанные `astro:assets`, и содержимое `public/` (фавиконки, `og-image.svg`,
`robots.txt`, `site.webmanifest`). Клиентского JS-бандла нет — только инлайн-скрипты в
разметке.

## Хостинг

Подойдет что угодно, отдающее файлы:

- **Vercel** — фреймворк Astro, сборка `npm run build`, вывод `dist`
- **Netlify** — то же самое
- **GitHub Pages** / **Cloudflare Pages** — раздача из `dist/`
- **nginx / Caddy / S3** — скопировать `dist/`

Требований к рантайму, редиректам и заголовкам нет; 404 отдается статическим
`dist/404.html`.

## Чеклист перед деплоем

1. `npm run astro check` — без ошибок типов.
2. `npm run build` — сборка проходит.
3. `dist/sitemap-0.xml` не содержит `/v1` и `/resume`.
4. `/resume` в превью печатается страница в страницу (просмотр печати в браузере).
5. Три локали открываются: `/`, `/ru/`, `/uz/`; переключатель языка ведет на парные адреса.
