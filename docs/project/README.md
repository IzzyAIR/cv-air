# Техническая документация

Устройство проекта: от маршрута до сборки. Каждый файл отвечает за один слой.

| Файл                            | Зона ответственности                                                   |
| ------------------------------- | ---------------------------------------------------------------------- |
| [pages.md](pages.md)            | Маршруты, `getStaticPaths`, canonical/hreflang, sitemap, 404            |
| [components.md](components.md)  | Компоненты v2 и v1, layouts, props, кто что рендерит                    |
| [content.md](content.md)        | `types/cv.ts`, локальные бандлы, слой сервисов, добавление языка/секции |
| [logic.md](logic.md)            | `consts.ts`, хелперы `v2/ui.ts`, `v2/logos.ts`, клиентские скрипты      |
| [resume.md](resume.md)          | A4-документ `/resume`: пагинация, печать, ATS-контракт                  |
| [deploy.md](deploy.md)          | Скрипты, сборка, статический вывод, хостинг                             |

## Три поверхности из одного контента

| Маршрут                      | Компонент      | Статус                       |
| ---------------------------- | -------------- | ---------------------------- |
| `/`, `/ru/`, `/uz/`          | `V2Page`       | живой сайт, индексируется    |
| `/v1`, `/ru/v1`, `/uz/v1`    | `CvPage`       | архив первого дизайна, noindex |
| `/resume`, `/ru/resume`, ... | `ResumePage`   | печатное CV, noindex          |

Все три собираются из одних и тех же локальных бандлов через один слой сервисов.
Дублирования контента между поверхностями нет и быть не должно.
